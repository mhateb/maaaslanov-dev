# Версия приложения

При классификации оценивай изменения относительно указанной базы:

- `patch` — исправление ошибки или небольшое изменение существующего поведения.
- `minor` — новая возможность, совместимая с существующим поведением.
- `major` — несовместимое изменение пользовательского контракта, например удаление или перенос публичного маршрута без перенаправления.
- `skip` — изменения только документации, инструментов разработки или самой версии.

Если запрошено несколько изменений, выбирай наибольшее повышение из тех, которые требуются. При автоматическом запуске верни только одно из четырёх слов.

Версия хранится в `package.json` и `package-lock.json`. Обёртка применяет выбранный тип через npm. Если версии ещё нет, при первом повышении она устанавливает `0.1.0`.
